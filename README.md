# Matthew Brandenburg Engineering Portfolio

Static portfolio deployed to [matthew-brandenburg.com](https://matthew-brandenburg.com) through GitHub Pages and Cloudflare.

## Structure

- `index.html` — landing page and engineering identity
- `about.html` — education, capabilities, credentials, and leadership
- `projects.html` — five expandable engineering project summaries
- `experience.html` — engineering and employment experience
- `contact.html` — privacy-conscious contact actions
- `resume.html` — compatibility redirect to `experience.html`
- `docs/website-content-brief.md` — durable content source of truth
- `assets/site.css` and `assets/site.js` — shared presentation and interactions

The public site intentionally does not host a directly downloadable résumé. Visitors request it through a pre-addressed email action.
